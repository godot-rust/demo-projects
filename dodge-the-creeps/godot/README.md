# Dodge the Creeps

This is a simple game where your character must move and avoid the enemies for as long as possible.

Rust port of the game featured in the ["Your first 2D game"](https://docs.godotengine.org/en/latest/getting_started/first_2d_game/index.html)
tutorial of the Godot documentation. The gameplay logic lives in [`../rust/src`](../rust/src); the Godot project only
contains scenes and assets.

Language: Rust (via [godot-rust](https://github.com/godot-rust/gdext))

Renderer: Vulkan Mobile

Upstream GDScript demo: [2d/dodge_the_creeps](https://github.com/godotengine/godot-demo-projects/tree/master/2d/dodge_the_creeps)
