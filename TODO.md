## 1. Commit `.import` files

Root `.gitignore` excludes `*.import`, so Godot regenerates texture UIDs on every fresh checkout. That causes the
`ext_resource, invalid UID` errors that `.github/other/check-example.sh` has to filter out, and the UID churn that shows
up in scene diffs whenever a contributor re-imports assets locally.

Godot's own guidance is to commit `.import` files -- they are the only thing that makes resource UIDs stable across
machines. Not done here because they must be generated by the Godot version the repo targets, by opening each project in
the editor once; committing whatever is in a given working tree bakes one contributor's editor version into the repo.
It also adds ~30 tracked files across four demos, so it deserves its own PR.

When doing it: remove `*.import` from `.gitignore`, open each of the four projects once in the current stable editor,
commit the generated files, then drop the UID filter and its TODO comment from `check-example.sh`.

## 2. net-pong: `.godot/extension_list.cfg` is not tracked

`net-pong/godot/.gitignore` used to re-ignore `.godot/`, which defeated the root `!**/.godot/extension_list.cfg`
un-ignore. That file has been removed, but net-pong's `extension_list.cfg` still needs to be generated (open the project
in the editor once) and committed, so the demo can run headless without opening the editor first -- the other three
demos already have it.

## 3. `compatibility_minimum` vs. targeted Godot version

All four `rust.gdextension` files declare `compatibility_minimum = 4.3`, while `project.godot` features say 4.5 and CI
runs 4.6 + nightly. A minimum is not a target, so this is not wrong -- but nobody verifies that the demos still load on
4.3. Either test against the declared minimum, or raise it to what is really supported.

## 4. Comment line width

Comments added during the review pass wrap at ~100 chars rather than filling the 145 the repo allows, e.g. in
`dodge-the-creeps/rust/src/main_scene.rs` and `player.rs`. Purely cosmetic; reflow when next touching those files.
